# SENTRIXA

## Cybersecurity Solutions

SENTRIXA is a cybersecurity platform designed to help users monitor and improve their website security.

## Main Features

- Website Security Scanning
- SSL Certificate Checking
- Security Headers Analysis
- Security Score
- Security Reports
- Security Alerts
